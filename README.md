dotfiles
========

This is the repository of [Daniel Rudolf](https://www.daniel-rudolf.de)'s ([@PhrozenByte](https://github.com/PhrozenByte)) [dotfiles](https://en.wikipedia.org/wiki/dotfile), managed with [Chezmoi](https://www.chezmoi.io/).

Dotfiles includes user-specific configuration and setup files. They are supposed to be shared between different machines, possibly even different Linux distributions. However, everything is highly adapted to PhrozenByte's personal use and thus likely not suitable for others to use. Anyway, if you want to, you can, it's free and open-source software (FOSS) after all, released under the terms of the [MIT License](./LICENSE).
